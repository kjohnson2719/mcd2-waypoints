# Changelog

## 1.1 (2026-10-09)

- Tells you when a new version is out, in a notice made of the game's own panel (asks GitHub when the game starts, at most every 6 hours; a setting turns it off). With several of these mods installed, one notice lists them all.
- Built on the shared mod kit (ModKit): no change in how it plays.

## 1.0 (2026-10-09)

First release.

- Set waypoints on the map screen with a controller (crosshair) or a mouse (cursor), snapping onto hovered map markers.
- Set waypoints in the world under the mouse (ground or minimap), or by pinging.
- A walkable route to the waypoint, shown with the game's guidance line on the guidance button, and on the map and the
  minimap; the waypoint's distance, and an arrow when it's off screen or beyond the minimap.
- Waypoints belong to their region (the Overworld, the Sift) and guide only there.
- A "Waypoint Reached" banner in the game's area banner style.
- Soulstorm generators shown on screen, on the minimap and on the map.
- A "Set Waypoint" hint with the game's button icon on the map screen; settings in the game's Mods tab.
